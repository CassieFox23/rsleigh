# rsleigh v0.6.0 release notes

Install the [v0.6.0 CLI](https://crates.io/crates/rsleigh/0.6.0) with:

```bash
cargo install rsleigh --version 0.6.0 --locked
```

Prebuilt archives for macOS (arm64/x86-64), Linux glibc (arm64/x86-64), and
Windows x86-64 are on the
[v0.6.0 release page](https://github.com/ShaneBreazeale/rsleigh/releases/tag/v0.6.0),
each with a SHA-256 checksum.

## Release notes

Agents can discover every operation from one catalog. `rsleigh --capabilities`
lists schemas, typed flags, effects, limits, runnable examples, and stable
error codes. Dispatch validation, `--help`, and the new `rsleigh --mcp` stdio
server all read the same catalog. `--xrefs` and `--search` are part of it,
with `rsleigh.xrefs/v1` and `rsleigh.search/v1` JSON.

Evidence is portable. `--evidence-store` writes content-addressed
`rsleigh.evidence/v1` records. Bundles move them between sessions, and
`--investigate` tracks a question, its evidence, and its answer across
revisions. `--compare` reports per-dimension function differences with
explicit `unknown` results.

Decompiler output changed in response to an external comparison against
Ghidra (morluto/rea#1389):
- Output is deterministic across runs.
- Code reached through jumps and `.cold` fragments stays in the function.
- Shared returns keep each path's value.
- Jump tables print as `switch`, including tables whose base is set far
  before the dispatch, and constant divisions print as `/` and `%`.
- Calls through a pointer stored in data print as `(*DAT_<slot>)(...)`.
- Lift order follows SLEIGH `build` statements.
- `--xrefs` no longer prints decoder panics or leaks internal temporaries as
  callee names, and it counts tail-call jumps.
- A self-referencing value no longer overflows the stack in constant folding.

See the [changelog](../../CHANGELOG.md#060---2026-10-11) for the full list.

## Migration

| Change | What to do |
|---|---|
| ELF and Mach-O `imagebase` is the load base (lowest `PT_LOAD` page, `__TEXT` vmaddr) | Content IDs of new ELF and Mach-O evidence records differ from 0.5.0 records for the same input. Old records still verify. Do not deduplicate across versions by ID. |
| `--xrefs` and `--search` validate their flags | Remove flags these modes never used (for example `--fid`); they now fail with `unsupported_option`. |
| `--xrefs` and `--search` report bounded scans | Exit 2 (`partial`) means at least one function was longer than the 4,096-byte scan window; see `limits.truncated_scans`. |
| A first argument beginning with `-` is an option | Write such file names as `./NAME`. |
| `--diff` renders the comparison model | Duplicate names are reported as ambiguous; unreadable inputs fail. |

Rebuild Rust integrations against the 0.6 crate family. Known limits are
unchanged from 0.5.0 except where the changelog says otherwise. A recovered
table with more than about 250 cases prints a `switch` that stops early
(the CFG keeps every case), and `rsleigh-generate` output is not yet
byte-for-byte reproducible across runs.
